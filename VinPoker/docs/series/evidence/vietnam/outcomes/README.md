# Vietnam Outcome Evidence Inbox

This directory is for public, observed tournament-result evidence only. It is separate from the D1A schedule-poster inbox. A schedule is planned supply, never proof of an outcome.

Accepted evidence must identify the organizer, series, event or flight, and the published result. Examples include an official result poster, official tournament report, official organizer result page, established public tournament-reporting page, final-result PDF, public post explicitly stating entries or prize pool, and a satellite result that explicitly states awarded seats.

Rejected evidence includes an unsourced screenshot, a cropped number without event identity, user recollection, estimated entries, comment speculation, likes or views, a schedule poster without an outcome, and any private player list.

Store untouched owner-provided files in `inbox/`. A reviewer may copy a byte-identical accepted source to `reviewed/` only when its SHA-256, byte length, approved media type, publication state, and capture time are recorded. URL-only evidence may be inspected at intake but cannot enter a release. Put rejected material and its reason in `rejected/`; it must never enter a release. No empty, missing-only, partial-only, future-only, or fixture release is generated merely because these folders exist.

See `D1B_VIETNAM_OUTCOME_EVIDENCE_FOUNDATION.md` for the intake and review workflow.
